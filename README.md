# 💧 Счётчики воды — Water Meter App

Android-приложение для учёта показаний счётчиков холодной воды.  
Фотографируете счётчик — приложение распознаёт показания и серийный номер, сохраняет историю и отправляет отчёт в Telegram.

---

## 📱 Функционал

### Вкладка «Счётчики»
- Список всех добавленных счётчиков (до 30 шт.) с последними показаниями и датой
- Тап на карточку → экран истории показаний
- Долгое нажатие → меню редактирования / удаления счётчика
- Кнопка **«Отправить в Telegram»** — отправляет таблицу показаний за текущий месяц
- FAB **«+»** — быстрый переход на вкладку добавления

### Вкладка «Добавить»
- **Шаг 1 — Номер счётчика:** тап на иконку 🔍 запускает полноэкранный сканер QR-кодов и штрихкодов в реальном времени
- **Шаг 2 — Показания:** тап на иконку 📷 открывает камеру с прямоугольным прицелом; после съёмки фото автоматически обрезается по зоне прицела и распознаётся ML Kit OCR (только целые числа)
- Поля заполняются автоматически, при необходимости редактируются вручную
- Защита от ложного распознавания: показания не принимаются если совпадают с серийным номером

### Экран «История» (открывается тапом на счётчик)
- Карточка с последними показаниями и расходом за период
- Столбчатый график потребления за последние 6 периодов
- Список всех показаний с датами (редактирование и удаление)
- Кнопка **«+ Добавить показания»** — ручной ввод нового показания для данного счётчика

### Вкладка «Настройки»
- Настройка **Telegram-бота**: токен и Chat ID
- **Экспорт** — сохраняет все данные (счётчики, показания, настройки) в JSON-файл в память телефона
- **Импорт** — загружает данные из ранее сохранённого JSON-файла (merge: существующие данные не удаляются)
- Версия приложения

## 🏗️ Архитектура

```
MVVM + Clean Architecture
├── data/
│   ├── db/          — Room SQLite (Meter, Reading)
│   ├── model/       — Entity + Relations
│   └── repository/  — MeterRepository
├── di/              — Hilt DI
├── ml/              — MeterOcrHelper (ML Kit Text Recognition)
├── ui/
│   ├── meters/      — Вкладка «Счётчики»
│   ├── add/         — Вкладка «Добавить» + BarcodeScannerActivity + MeterCameraActivity
│   ├── history/     — Экран истории (открывается из списка)
│   └── settings/    — Вкладка «Настройки»
└── util/
    ├── TelegramSender      — Отправка отчёта в Telegram Bot API
    ├── ExportImportManager — Экспорт/импорт данных в JSON
    ├── SettingsManager     — DataStore (токен, Chat ID)
    ├── ImageUtils          — Кроп и сохранение фото в галерею
    └── DateUtils           — Форматирование дат
```

## 🚀 Сборка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/YOUR_USERNAME/WaterMeterApp.git
cd WaterMeterApp
```

### 2. Сгенерировать gradle-wrapper.jar (один раз)
```bash
# Способ А — открыть в Android Studio (автоматически)
# Способ Б — командная строка
gradle wrapper --gradle-version 8.2
```

### 3. Запустить
- Выбрать устройство (API 26+) и нажать Run
- Или через командную строку: `./gradlew assembleDebug`

---

## ⚙️ Настройка Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен
2. Напишите боту любое сообщение
3. Откройте `https://api.telegram.org/bot{TOKEN}/getUpdates` → найдите `"chat": {"id": ...}`
4. Введите токен и Chat ID в приложении → вкладка **Настройки**

## 💾 Экспорт / Импорт данных

Формат файла — JSON (`WaterMeter_backup_YYYYMMDD_HHmmss.json`):
```json
{
  "version": 1,
  "exportDate": "2026-04-01T10:00:00",
  "settings": { "botToken": "...", "chatId": "..." },
  "meters": [
    {
      "serialNumber": "ВСХ-15-00384521",
      "name": "Кухня",
      "readings": [
        { "value": 3469, "date": 1743465600000 }
      ]
    }
  ]
}
```

- **Экспорт**: Настройки → Экспорт → выберите папку для сохранения
- **Импорт**: Настройки → Импорт → выберите ранее сохранённый файл
- Стратегия импорта: **merge** (данные добавляются, существующие не удаляются)
