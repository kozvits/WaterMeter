# 💧 Счётчики воды — Water Meter App

Android-приложение для учёта показаний счётчиков холодной воды с поддержкой OCR-распознавания и отправкой в Telegram.

---

## 📱 Возможности

| Функция | Описание |
|---|---|
| 📷 Камера / Галерея | Съёмка счётчика или выбор фото из галереи |
| 🤖 OCR (ML Kit) | On-device распознавание показаний и серийного номера |
| ✂️ Обрезка фото | Автоматическая обрезка и сохранение в галерею |
| 📋 Список счётчиков | До 30 счётчиков, карточки с последними показаниями |
| 📊 История | График потребления и список всех показаний |
| ✏️ Редактирование | Изменение и удаление счётчиков и показаний |
| ✈️ Telegram | Отправка таблицы показаний за текущий месяц |
| ⚙️ Настройки | Токен бота и Chat ID |

## 🛠️ Технологии

- **Kotlin** + Coroutines + Flow
- **Hilt** — внедрение зависимостей
- **Room** — локальная база данных
- **Navigation Component** — навигация + BottomNavigationView
- **ML Kit Text Recognition** — OCR на устройстве (офлайн)
- **CameraX** — захват изображений
- **MPAndroidChart** — график потребления
- **OkHttp** — HTTP-клиент для Telegram Bot API
- **DataStore** — хранение настроек
- **Glide** — загрузка изображений

## 🚀 Быстрый старт

### 1. Клонировать репозиторий
```bash
git clone https://github.com/YOUR_USERNAME/WaterMeterApp.git
cd WaterMeterApp
```

### 2. Открыть в Android Studio
- File → Open → выбрать папку проекта
- Дождаться синхронизации Gradle

### 3. Запустить
- Выбрать устройство или эмулятор (API 26+)
- Run → Run 'app'

## ⚙️ Настройка Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте **токен бота**
4. Напишите боту любое сообщение
5. Откройте `https://api.telegram.org/bot{TOKEN}/getUpdates`
6. Найдите поле `"chat": {"id": ...}` — это ваш **Chat ID**
7. Введите токен и Chat ID в приложении → вкладка **Настройки**

## 📸 Как работает распознавание

1. Пользователь фотографирует счётчик
2. ML Kit Text Recognition анализирует изображение **на устройстве** (без интернета)
3. Регулярные выражения извлекают:
   - **Показания**: 5–8 цифр, возможно с дробной частью (напр. `147.832`)
   - **Серийный номер**: буквенно-цифровая комбинация (напр. `ВСХ-15-00384521`)
4. Поля заполняются автоматически — пользователь может скорректировать
5. Фото обрезается по центру и сохраняется в галерею
